The Grendel One Project

The Grendel One project is a long term project allowing me to explore robotics, machine learning and artificial intelligence in my free time. Below you can find my working documents, notes, diagrams and everything about the project. The goal is to build a android like robot with AI capabilities as well as the ability to interact with the world around it. I started this project two years ago, and it is a work in progress.
